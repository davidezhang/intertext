# Intertext product plan

Status: the free component, studio, integration skill, and starter examples are maintained in this repository. The paid offering below is planned; there is no paid pack or checkout yet.

## Free product

Keep the native Web Component, React bindings, inline editing and placement, current motion controls, and code export available under MIT. The public studio is a useful product on its own and demonstrates the quality of the component.

Commercial use, modification, redistribution, and sale of the MIT code are permitted under its license. A premium purchase buys additional content or a service; it does not buy permission that users already have under MIT. Third-party demo media and dependencies retain their own licenses.

## Recommended public repository

Keep the runtime, React bindings, integration skill, basic studio, local export, documentation, tests, and starter examples together in the public core repository. This lets developers inspect the dependency, report issues, contribute fixes, and teach their agents the same supported integration. Website-hosted skill installation works independently of GitHub visibility.

Keep the name Intertext for the product and `intertext-dev` for the package. The free skill should lead to a working result without requiring an account or paid plan. React support, accessibility, and reliable export remain part of the free foundation.

## First paid product: Composition Pack 01

Start with a one-time purchase of polished, adaptable compositions built on the free component. The intended audience is designers and developers building portfolios, editorial sites, and product pages.

Initial scope:

- **Portfolio introduction:** an expressive headline with inline still and motion media, with layouts for short and long names.
- **Editorial feature:** a large typographic lead with multiple media placements and responsive reading widths.
- **Product story:** a complete hero composition with supporting copy, a call to action, and coordinated media motion.

Each composition should include React/TypeScript source, responsive styles, a small set of motion presets, integration instructions, and reduced-motion behavior. Use original media or placeholders that customers replace. The existing stock demo assets are not the paid product.

The starter examples (editorial, portfolio, product, event, studio, and field notes) remain free. A paid pack must add substantial new compositions and variants: complete sections, coordinated typography, responsive layouts, art direction, and useful integration guidance. Do not repackage the current starter examples as the paid offering.

The value is the finished composition and the time it saves: typography, spacing, responsive behavior, and motion already work together. Complete and validate the pack before setting a price or accepting payment.

## Distribution and licensing boundary

- Keep premium source and downloadable archives in a separate private repository or private storage. Do not commit them to the core repository or its history, even while the core repository remains private.
- Let the public site show previews and explain what a purchase includes. If previews ship executable code to a browser, treat that code as inspectable.
- Deliver downloads after a server verifies payment or entitlement. A hidden button or client-side flag is not access control.
- Ship a dedicated commercial license with each premium pack. The intended terms allow use and modification in unlimited personal and client end products while restricting redistribution of the pack as a competing template or component collection. Define seats and included updates before launch. This plan is not that license.
- Purchased files should remain usable without a recurring subscription. Premium terms must not restrict the underlying MIT component or code already released under MIT.

## Later recurring offering

Consider a subscription only when the studio provides an ongoing service worth paying for: saved cloud projects, shared brand presets, team libraries, or collaboration. Local editing and code export remain part of the free product. Build this after validating demand for the composition pack.

## Reference: Transitions.dev

As reviewed on October 26, 2026, Transitions.dev combines a public repository and free skill with paid recipes, an authenticated Pro skill installer, and hosted services. Its repository has a mixed license: tooling is MIT, while transitions and skills carry a restriction against redistributing the collection as a competing library. Intertext's recommended MIT core is a deliberate simpler choice, not a claim that Transitions.dev's entire product is MIT. Public availability does not reveal its revenue or prove demand for an equivalent Intertext plan.
